### README.md

#### Coden Interest Calculator

A small Vite + React + TypeScript application for exploring compound-interest
growth. This is the first benchmark repository for the Coden local AI coding
assistant.

##### Run locally

```bash
npm install
npm run dev
```

##### Validate

```bash
npm test
npm run lint
npm run build
```

##### Example

With a starting balance of $1,000, no additional contributions, a 7% annual
return, 20 years, and annual compounding, the projected balance is approximately
$3,869.68.

##### Notes

This app is for educational planning only. It does not account for taxes,
inflation, fees, account-specific rules, or contribution limits.
